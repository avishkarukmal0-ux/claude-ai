# 🔬 Niche Pain Research — What Every Shop Struggles With (2025–26)

Back to [[Home]] · Related: [[Go-To-Market]] · [[Customer-Discovery]] · [[Positioning]] · [[Feature-Inventory]]

> **Desk research, July 2026.** Grounded per-niche pains across the Phase-1 target shops, used to design the Common Core vs Vertical Modules split in [[Go-To-Market]]. **This is priors, not truth** — validate in the field via [[Customer-Discovery]] before pitching any figure. Sources: ACS, UK Finance, GOV.UK/HMRC, WRAP, The Grocer, betterRetailing, NCB, FSA. Margin %, waste %, and owner quotes are directional (trade-press/secondary) unless marked hard-sourced.

## 🌍 The Universal Core (build once — every small shop feels these)
Evidence-backed pains shared across **all** niches → this is what justifies the shared core:

| Universal pain | Evidence | Core feature it implies |
|---|---|---|
| **★ MTD for Income Tax (live Apr 2026)** | Sole traders >£50k turnover must keep digital records + file 4 quarterly submissions + final declaration (£30k in 2027, £20k 2028). Turnover-based → even thin-margin shops caught. (GOV.UK) | **Auto-capture every sale + expense → MTD-ready quarterly export.** A legally-forced, dated, universal "must-have." |
| **Shrink / crime** | ~£6,259–£7,137 cost of crime per store; 5.8–6.2m theft incidents; a "~10–11p crime tax" per transaction. (ACS Crime Report 2025/26 — hard-sourced) | Till-exception / refund / no-sale analytics; auditability. |
| **Age verification** | Multi-threshold (alcohol/tobacco/vape/lottery/knives) at one till; ministerial lobbying 2025. | Enforced prompt + refusal/ID audit log; digital-ID ready. |
| **Ordering / admin drain** | "Serve the customer or do the paperwork" — owners do books after close; ~16 hrs/week admin (general SME, directional). | Sales-velocity suggested orders + invoice↔delivery reconciliation. |
| **Margin visibility** | PMP margins squeezed to ~15–22% vs ~30% branded; wage/NIC rises can't pass to price-marked lines. | True margin per line; flag cost-rise erosion. |
| **Card fees** | Cash <10% of transactions (UK Finance 2025, hard-sourced); fees bite on low baskets. | The [[Positioning]] payment-margin play. |

## 🏪 Per-niche pains → the Vertical Module each implies

| Niche | Signature pain (money/time) | Vertical module |
|---|---|---|
| **Off-licence** | Duty-driven repricing; mispricing = margin *and* compliance breach | **MUP formula pricing** (65p × ABV × litres), strength-based duty repricing, DRS deposit handling (2027) |
| **Convenience / mini-mart** | Fresh/chilled wastage; PMP margin; multi-delivery-app chaos | FEFO date-code waste mgmt + cold-chain markdowns; delivery-app order aggregation |
| **Newsagent / CTN** | Legacy categories collapsing (news −80%, tobacco halved 2021–25) | **Magazine sale-or-return** reconciliation; HND round billing; **tobacco track-&-trace** scan capture |
| **Ethnic / int'l grocer** | Festival demand mis-forecast (Eid/Diwali); import spoilage; huge multilingual SKU base | **Cultural-calendar demand forecasting**; multi-cash-&-carry ordering; halal traceability |
| **Greengrocer** | Spoilage (headline loss); stale shelf price vs daily-moving wholesale cost | Cost-linked repricing; **loose-weight scale↔EPOS**; dynamic markdown (only ~5% of UK markdowns are data-driven — WRAP) |
| **Butcher / fishmonger** | Carcass yield costing; use-by write-offs; recall readiness | **Cut/yield costing**; use-by mgmt; batch/lot traceability; QUID + allergen labels; scale |
| **Bakery / deli / farm shop** | Bake-to-demand gamble (24–48hr shelf life); mixed-rate VAT | **Production forecasting**; **PPDS/Natasha's Law label generation**; per-SKU hot/cold VAT logic |
| **Vape / CBD** | Regulatory storm → range rebuilds + write-offs; fines | **Compliance-by-design**: age+refusal log, MHRA/FSA legality flags, **VPD duty + duty-stamp tracking** (£2.20/10ml, Oct 2026) |
| **Health-food** | Expiry write-offs (~10–18% of stock, directional); can't legally claim benefits | **Batch/expiry FEFO** + short-dated markdown; health-claims whitelist; allergen/PPDS |
| **Discount / pound** | One-off no-barcode job-lot stock; perpetual repricing; dead stock | **Photograph-and-price ad-hoc SKU entry**; batch labelling; sell-through/dead-stock reporting |
| **Pet shop** | Beaten on staples price; subscription/auto-ship gap; dated-food spoilage | Pet-linked loyalty + **repeat-order/"subscribe" prompts**; dated-stock expiry; welfare/feed compliance fields |
| **★ Market traders** | Phone IS the business; nightly cash+card+stock reconciliation; MTD | **Phone-first unified inventory + cash/card reconciliation + MTD export** — the gap SumUp/Zettle leave open |

## 🎯 The strongest cross-cutting wedges (ranked)
1. **★ MTD auto-capture (Apr 2026)** — universal, legally forced, live *now*, and hits sole traders who keep no digital records. The clearest "must-have" the research surfaced. **New headline wedge.**
2. **Perishable-waste forecast + dynamic markdown + spoilage analytics** — biggest *untooled* money leak across all fresh niches, amplified by pay-to-bin waste law (Simpler Recycling >5kg/week).
3. **Compliance-by-design** — vape especially (fine risk + constant rule changes), plus age-verification everywhere. Encodes UK regulatory logic horizontal POS ignore → the moat.
4. **Shrink auditability** — quantified universal drain (~£6–7k/store).

## Market-trader validation (the phone-first thesis)
Confirmed: traders already run payments on a phone (SumUp 1.69% / Zettle 1.75% / Square), tolerate per-sale fees, no contract. **Stock is the under-served layer** — most use a notebook / mental count / cash tin (*notebook usage inferred from provider marketing, not a hard stat*). The unmet gap = **unified inventory + cash/card reconciliation + MTD-ready records in one phone app**, not "card reader with an afterthought stock tab." Strong fit for Phase 1.
